El trabajo práctico implementa de forma progresiva el alta de alumnos en Python, usando diccionarios y listas:

Ejercicio 1: Registro de un solo alumno (datos en un diccionario).
Ejercicio 2: Registro múltiple de alumnos con un bucle for (cantidad definida por el usuario).
Ejercicio 3: Se agrega validación de edad (debe ser entre 17 y 99 años). Si no cumple, el registro se descarta.
Ejercicio 4: Bucle infinito hasta escribir "SALIR". Se valida que el DNI no esté repetido antes de registrar.
Ejercicio 5: Se guarda el registro en un archivo registros.txt usando una función, con manejo de errores (try/except) para DNI y edad.
